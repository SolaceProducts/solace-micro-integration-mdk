# Contributing

Contributions are welcome.

1. **Fork** the repository.
2. **Make your change** on a branch.
3. **Commit** it with a clear message.
4. **Open an issue** describing the problem or improvement, if one doesn't already exist.
5. **Open a pull request** and reference the issue.

Please make sure `./mvnw clean verify` passes before opening the PR. Integration tests need Docker running.

Questions and ideas are just as welcome as code — the [Connectors & Integrations](https://community.solace.com/c/connectors-integrations/9) category on [Solace Community](https://community.solace.com/) is the best place for those.
