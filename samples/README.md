# Samples

This directory contains sample Micro-Integration projects for the Solace Micro-Integration Development Kit (MDK).

## ABC Service Integration

A sample Micro-Integration project demonstrating AI-enabled integration between the Solace event broker and the ABC service using the Solace MDK and Spring Cloud Stream. The ABC service is a fictitious service created for example purposes only. The project includes the ABC service and client, a custom Spring Cloud Stream binder, test support with Testcontainers, and a Micro-Integration application bridging Solace and ABC.

The `abc-integration` folder is a standalone project root — open it directly in your IDE. For full details see [abc-integration/README.md](./abc-integration/README.md).
