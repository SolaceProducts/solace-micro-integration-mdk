# ABC Parent

Parent POM for the ABC service ecosystem. The ABC service is a fictitious service created for demonstration purposes only. Contains two sub-modules:

- **[abc-service](./abc-service/README.md)** - A Spring Boot application that implements the ABC backend service with REST APIs for destination management, message publishing, polling, and acknowledgment.
- **[abc-client](./abc-client/README.md)** - A Java client library for interacting with the ABC service.
